# BTC5m archive

The BTC5m runtime is archived and is not part of the public sports observatory.

- Last known reference commit: `eb21efc`
- Historical data remains under `data/` and in Git history.
- The old dashboard and strategy code remain recoverable from the commit history.
- Do not enable `polymarket-live.service` or `polymarket-dashboard-live.service` for this project.
- Telegram status summaries remain disabled.

This archive is intentionally documentation-only. The public deployment must not import
the BTC5m strategy, live broker, wallet synchronizer, or order execution clients.
